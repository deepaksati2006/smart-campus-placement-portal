# Smart Campus Placement Portal 🎓💼
> A MERN Stack platform to digitize and automate college placements.

**Developed by: Deepak Sati** | [LinkedIn](https://linkedin.com) | [Live Demo](https://your-link-will-be-here.vercel.app)

![Portal Banner](https://via.placeholder.com/800x400?text=Smart+Campus+Placement+Portal)

### 🚀 Key Features
- **For Students:** Registration with OTP, Resume Builder, One-Click Job Apply, Real-time Status Tracking (Applied, Shortlisted, Offered)
- **For Recruiters:** Post Jobs, Filter Students by CGPA/Skills/Branch, Shortlist Candidates
- **For TPO Admin:** Full Analytics Dashboard - Placement %, Branch-wise Reports, Company Management

### 🛠️ Tech Stack
- Frontend: React.js, Tailwind CSS, Axios
- Backend: Node.js, Express.js
- Database: MongoDB
- Authentication: JWT & OTP Verification
- Tools: Nodemailer, Cloudinary for resume upload

### 📸 Screenshots
- Student Dashboard - Shows 24 Applications, 58 Active Companies
- Admin Analytics - 78% Placement Rate Chart

### ⚙️ How to Run
1. Clone repo: `git clone https://github.com/deepaksati2006/smart-campus-placement-portal.git`
2. Client: `cd client && npm install && npm run dev`
3. Server: `cd server && npm install && npm start`
